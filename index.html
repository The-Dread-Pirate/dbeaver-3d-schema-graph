DBeaver 3D Schema Graph

This is an Eclipse p2 update site for a DBeaver plugin. It is not meant to be opened in a browser.

Install

  1. In DBeaver, choose Help → Install New Software… → Add…
  2. Use this page's address as the location: https://the-dread-pirate.github.io/dbeaver-3d-schema-graph/
  3. Select DBeaver 3D Graph, finish the wizard, and restart DBeaver.

DBeaver will warn that the content is unsigned. That is expected.
